# Wiskers custom cat animation archive v1

This is the preserved custom animation set from the website design work. The live website no longer loads or displays the cat. These files and the preview pages remain in the repository for reference or future use; Vite does not copy this artifacts folder into dist/.

Each PNG is a transparent four-frame strip with 120 × 96 pixel cells, a shared foot anchor, and a consistent pixel-art palette. OPENING_FALL.png is a separate 16-frame sequence made for the opening fall study.

## Rest and routine

- SLEEP.png, WAKE.png, STRETCH.png, LICK.png, EAT.png

The original 27 clips cover directional movement, reactions, climbing, jumping, recovery, play, and rest. The fall study was planned as SLIP → TWIST → RECOVER. The exact opening sequence previews the cat slipping from the word “content” toward “input,” with an impact bounce on landing. The previews are useful for reviewing the artwork, but do not represent the current live design.
