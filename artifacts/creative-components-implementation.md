# Creative component references for the Wiskers homepage

The homepage uses one native scroll timeline for the visual moments below. It keeps the motion reversible with scroll, adapts to the viewport, and stays light on mobile. No Framer component code or third-party runtime was copied into the site; these are original, small implementations informed by the public references below.

| Reference | Availability on 18 October 2026 | Wiskers adaptation | Free GitHub reference |
| --- | --- | --- | --- |
| [Runaround Text Wrap](https://www.framer.com/marketplace/components/runaround-text-wrap/) | Free listing; Framer Limited Commercial License | A short thesis paragraph wraps around a small Wiskers orbit mark using CSS `shape-outside`. | [responsive-text-wrap-image](https://github.com/SadatRiyad/responsive-text-wrap-image) (MIT) |
| [Hover Water Effect](https://www.framer.com/marketplace/components/hover-water-effect/) | $8; Single-Use | A small SVG displacement filter adds a restrained ripple to the existing expertise-flow lines; scroll remains the primary driver. | [jquery.ripples](https://github.com/sirxemic/jquery.ripples) (MIT) |
| [SpiralGallery Pro](https://www.framer.com/marketplace/components/spiralgallery-pro/) | Free listing; Framer Limited Commercial License | A thin spiral route guides the three existing tool examples; each example rolls by a few pixels and a fraction of a degree as it enters and leaves view. | [StudioDialect-WEBGLAnimation](https://github.com/Thakuma07/StudioDialect-WEBGLAnimation) (MIT) |
| [ASCII Pixels](https://www.framer.com/marketplace/components/ascii-pixels/) | Free listing; Framer Limited Commercial License | A tiny canvas renders a sparse ASCII signal over the existing flow diagram, driven by that section's scroll progress instead of a background video. | [ASCII](https://github.com/collidingScopes/ASCII) (MIT) |
| [Smooth Image Trail](https://www.framer.com/marketplace/components/smooth-image-trail/) | Free listing; Framer Limited Commercial License | Three small Wiskers star marks travel along the flow path and fade behind the scroll position, so the effect works without a mouse. | [cursor-effects](https://github.com/tholman/cursor-effects) (MIT) |
| [Hanging Card](https://www.framer.com/marketplace/components/hanging-card/) | Free listing; Framer Limited Commercial License | One paper-like “Buyer signal” note hangs beside the process heading and sways gently with scroll progress. | [pullcord](https://github.com/mortspace/pullcord) (MIT) |
| [Interactive Box Grid](https://www.framer.com/marketplace/components/interactive-box-grid/) | $10; Single-Use | The existing comparison checkboxes become a square-cornered, keyboard-operable tile grid; existing three-choice limit and result count remain intact. | [three.js](https://github.com/mrdoob/three.js) (MIT) was available in the project; native CSS and form controls keep this treatment lighter. |

Framer's current Community Terms allow free content to be modified in a commercial project, while prohibiting standalone redistribution. The paid components are not included. The repo links are MIT-licensed implementation references; this site uses its own markup and scroll logic rather than shipping those repos as dependencies.
