Canonical website source:
The Website folder in the local Tabby companion files, mirrored to the GitHub repository below.

Repository target:
wiskersofficial/wiskers-website

The repository contains only the website source and licensed public assets. The surrounding company vault must not be uploaded. The GitHub organization name is unchanged.

Local preview: npm ci, then npm run dev.
Production build: npm run build.
Build command for Cloudflare Pages: npm run build.
Output directory: dist.

The site is already served at wiskers.click through Cloudflare. A GitHub push did not trigger a visible production update at the last check. In the Cloudflare account that owns this existing site, inspect its Workers & Pages project. If it is a Direct Upload project, choose Create a new deployment, select Production, and upload wiskers-cloudflare-upload.zip from the local Website folder. If it is Git-integrated, inspect its build/deployment logs and confirm this repository and main branch are connected. Do not create a second project or change the domain's DNS to release this version.

Website domain: wiskers.click. The similarly spelled whiskers.click is not our domain. Preserve the existing DNS and mail records for hello@wiskers.click.

Customer contact: hello@wiskers.click.
