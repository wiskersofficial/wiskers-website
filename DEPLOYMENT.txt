WISKERS PUBLISHING HANDOFF

Canonical website source:
The Website folder in the local Tabby companion files, mirrored to the GitHub repository below.

Repository target:
wiskersofficial/wiskers-website

The repository contains the website source and preserved design artifacts. The surrounding company vault must not be uploaded. The GitHub organization name is unchanged.

Local preview: npm ci, then npm run dev.
Production build: npm run build.
Cloudflare build command: npm run build.
Cloudflare deploy command: npx wrangler deploy.
Static asset directory: dist.

The site is already served at wiskers.click through Cloudflare. A push to this repository triggers its Git-connected Cloudflare build. The wrangler.jsonc file targets the existing wiskers-website Worker and publishes dist/ as static assets. Keep this Worker name in sync with the Cloudflare project. Do not create a second project or change the domain's DNS to release this version.

Website domain: wiskers.click. The similarly spelled whiskers.click is not our domain. Preserve the existing DNS and mail records for hello@wiskers.click.

Customer contact: hello@wiskers.click.

The current release is cat-free. The Wiskers-generated sprite set and review pages are preserved under artifacts/cat-animation-v1/ and are not copied to dist/. Do not move them back under public/ unless a future design explicitly reintroduces the mascot.

There are no API keys or backend services required.
