The repository contains only the website source and licensed public assets. The surrounding company vault must not be uploaded. The GitHub organization name is unchanged.

Local preview: npm ci, then npm run dev.
Production build: npm run build.
Build command for Cloudflare Pages: npm run build.
Output directory: dist.

Free hosting: use Cloudflare Pages. Connect the website GitHub repository for automatic deployments, or use wiskers-cloudflare-upload.zip with a Direct Upload project. Direct Upload projects cannot later switch to Git integration.

Website domain: wiskers.click. The similarly spelled whiskers.click is not our domain. Add wiskers.click to the same Cloudflare account as the Pages project, select the free plan, and preserve existing DNS records. Before changing nameservers in Namecheap, make sure the current mail records for hello@wiskers.click are recreated in Cloudflare DNS so customer email keeps working. Enter the exact two assigned Cloudflare nameservers in Namecheap under Nameservers > Custom DNS. Then add wiskers.click under the Pages project's Custom domains and wait for domain and certificate activation.

Customer contact: hello@wiskers.click.
